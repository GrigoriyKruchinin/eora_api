# Eora

## Описание проекта
Eora — это [Telegram-бот](https://t.me/eora_quetions_bot), который отвечает на вопросы, используя данные с сайта EORA и YandexGPT. Бот помогает пользователям находить решения и примеры для различных бизнес-задач на основе имеющихся кейсов. 


**1. Что пробовали сделать. Что сработало, а что не очень.**

- Сначала я использовал OpenAI для интеграции GPT, но столкнулся с тем, что моя квота на запросы закончилась. Далее я переключился на использование Cohere API, но столкнулся с проблемой, что модель недостаточно качественно обрабатывает русскоязычный контент. После этого я решил попробовать YandexGPT, и это решение оказалось удачным: модель адекватно справляется с запросами на русском языке, что сделало её идеальной для моего проекта.

**2. Как оцениваю качество решения.**

- Оценка моего решения довольно высокая. Проект полностью соответствует заявленной третьей сложности задания. Бот успешно отвечает на запросы пользователей, обрабатывает ссылки, и обеспечивает корректные ответы на основе данных с сайта EORA.

**3. Что бы ещё добавил в решение, если бы было больше времени.**

- Во-первых, я бы создал абстрактный уровень для работы с различными API LLM, что позволило бы легко переключаться между различными моделями (например, OpenAI, Cohere, YandexGPT), просто добавляя новые реализации API, но сохраняя основную логику работы неизменной.

- Во-вторых, можно было бы значительно улучшить документацию: добавить подробные примеры использования, рекомендации по решению возможных проблем и настройке.

- В-третьих, я бы реализовал веб-интерфейс или полноценное API, что предоставило бы пользователям более удобный способ взаимодействия с моделью, особенно тем, кто не использует Telegram.


## Требования
- Проект разработан с использованием Python версии 3.12.
- Обратите внимание, что файл с переменными окружения `.env` сознательно добавлен в репозиторий для более простого запуска. В боевом проекте конфиденциальные данные попали бы в файл `.gitignore`.

## Установка и запуск

1. Клонируйте репозиторий:
```
git clone https://github.com/GrigoriyKruchinin/eora_api.git
```

2. Перейдите в директорию проекта:

```
cd eora_api
```

3. Создайте и активируйте виртуальное окружение:

```
python -m venv .venv
source .venv/bin/activate
```

Или используйте встроенные возможности создания и активации виртуального окружения вашей IDE.

4. Установите необходимые зависимости:

```
pip install -r requirements.txt
```

5. Если вы работаете через терминал, который не поддерживает автоматическую загрузку переменных окружения из `.env` файла, запустите следующую команду:

```
export $(grep -v '^#' .env | xargs)
```

> **Примечание:** Эта команда считывает все строки из `.env`, игнорируя комментарии (строки, начинающиеся с `#`), и экспортирует их как переменные окружения.

6. Спаршенные данные уже находятся в файле `data/parsed_data.json`, поэтому бот уже работает. Однако, если вы хотите добавить ссылку с новым кейсом с сайта EORA, вам нужно в файле `app/config.py` добавить в переменную `SOURCES_URLS` строку с ссылкой на новый кейс. А затем запустить скрипт:

```
python -m app.parser
```

7. Для запуска бота запустите скрипт:
```
python -m app.main
```

8. В Telegram перейдите в [чат с ботом](https://t.me/eora_quetions_bot) и нажмите `"/start"`, чтобы запустить бота. Далее вы можете задавать любые запросы, касающиеся компетенций консультанта EORA.
