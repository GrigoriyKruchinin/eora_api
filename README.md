# Eora

## Описание проекта
Eora — это [Telegram-бот](https://t.me/eora_quetions_bot), который отвечает на вопросы, используя данные с сайта EORA и YandexGPT. Бот помогает пользователям находить решения и примеры для различных бизнес-задач на основе имеющихся кейсов.

## Установка и запуск

1. Клонируйте репозиторий:
```
git clone https://github.com/GrigoriyKruchinin/eora_api.git
```

2. Перейдите в директорию проекта:

```
cd eora_api
```

3. Создайте и активируйте виртуальное окружение:

```
python -m venv .venv
source .venv/bin/activate
```

Или используйте встроенные возможности создания и активации виртуального окружения вашей IDE.

4. Установите необходимые зависимости:

```
pip install -r requirements.txt
```

5. Если вы работаете через терминал, который не поддерживает автоматическую загрузку переменных окружения из `.env` файла, запустите следующую команду:

```
export $(grep -v '^#' .env | xargs)
```

> **Примечание:** Эта команда считывает все строки из `.env`, игнорируя комментарии (строки, начинающиеся с `#`), и экспортирует их как переменные окружения.

6. Спаршенные данные уже находятся в файле `data/parsed_data.json`, поэтому бот уже работает. Однако, если вы хотите добавить ссылку с новым кейсом с сайта EORA, вам нужно в файле `app/config.py` добавить в переменную `SOURCES_URLS` строку с ссылкой на новый кейс. А затем запустить скрипт:

```
python -m app.parser
```

7. Для запуска бота запустите скрипт:
```
python -m app.main
```

8. В Telegram перейдите в [чат с ботом](https://t.me/eora_quetions_bot) и нажмите `"/start"`, чтобы запустить бота. Далее вы можете задавать любые запросы, касающиеся компетенций консультанта EORA.
